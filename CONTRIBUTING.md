# Contributing

Create a new branch with a name of what you have to do. We do not allow direct push to the main, please commit to that
branch.

Ideally, make sure you have passed CI when you need to merge the PR.

Best Commit Format:

- new feature: `feat: <description>`
- refactor: `refactor: <description>`
- documents: `doc: <description>`
- ci: `ci: <description>`
